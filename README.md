# BE2R-test-assignment
Тестовое задание: Планирование и управление движением шагающих роботов на основе обучения с подкреплением

# Введение
Управление движением шагающий роботов на основе обучения с подкреплением превращается из академической задачи в технологию, готовую к промышленному применению. роботы демонстрируют устойчивую ходьбу, бег, прыжки и преодоление сложного рельефа. За подобными демонстрациями скрывается фундаментальное ограничение: современные политики остаются преимущественно реактивными. Они отлично реагируют на текущее состояние среды, но плохо предсказывают, как эта среда изменится в ближайшем будущем, и почти не учитывают, как их действия повлияют на физическое взаимодействие с окружением.

# Анализ выбранных работ
## 1 Robust Quadrupped Locomotion via Evolutionary RL
Авторы: B. McArteer, K. Mason, 2025

Ключевая идея: Комбинация эволюционных алгоритмов (Cross-Entropy Method) с градиентными методами (DDPG, TD3).

Результаты:
- CEM-TD3 достигает наилучших результатов как на плоской, так и на пересечённой местности (значение награды 17611 на плоскости, 19574 на пересеченной местности).
- Чистые DRL-методы (DDPG, TD3) теряют производительность при переносе на пересеченную местность: DDPG падает до -1016, TD3 до -99.
- Эволюционные варианты сохраняют работоспособность: CEM-DDPG -25, CEM-TD3 19574.

Ограничения:
- Тестирование проводится только на одной задаче (ходьба) и одном типе сложной местности (случайный рельеф).
- Нет проверки на реальном роботе.
- Не исследуется перенос на принципиально новые типы препятствий (лестницы, бордюры, скользкие поверхности).
- Эволюционный поиск увеличивает вычислительную стоимость обучения.

Вклад: Демонстрация того, что популяционный поиск снижает переобучение и повышает робастность при domain shift.

## 2 Predictive Training with Latent Imagination for Visual Quadruped Navigation
Авторы: Y. Zhu et al., 2026

Ключевая идея: Auxiliary JEPA-style predictor + SIGReg регуляция, которые применяются только во время обучения и полностью отбрасываются на инференсе. Предсказатель учит рекуррентное состояние (LSTM-SRU) предсказывать своё следующее состояние.

Результаты:
- SRU-WM достигает 94.4% success rate на Nav task и 96.2% на DynObs task с collision rate 3.8%.
- Zero-shot перенос на Unitree Go2 без fine-tuning.
- Устранение SIGReg приводит к коллапсу представлений (SR падает до 86.0%, CR растёт до 12.1%).

Ограничения:
- Предсказание только на один шаг вперёд.
- Предсказывается только внешняя динамика (скрытое состояние), но не физические последствия действий.
- Проприоцепция не участвует в предсказательной ветви.
- Нет явного планирования — предсказание формирует лучшие представления.

Вклад: Доказательство того, что training-time predictive supervision может улучшить реактивную политику без дополнительных затрат на инференсе.
